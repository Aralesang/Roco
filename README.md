# Roco

基于 Node.js 的最小终端 Agent，当前支持 DeepSeek 对话、提供商连接和本地历史会话。暂不包含文件操作、命令执行等工具能力。

## 启动

需要 Node.js 22 或更新版本：

```bash
npm install
npm start
```

进入后输入 `connect`，选择 DeepSeek，输入 API Key，再从接口返回的列表选择模型，然后直接输入文字聊天。回复流式显示。

## 命令

输入框使用 `>` 提示符。命令可带 `/` 前缀，例如 `/connect`、`/session`。

输入 `/` 弹出命令菜单，继续输入按前缀筛选（如 `/c` 仅显示 `/connect`）；用 ↑↓ 选择、Tab 补全，再按 Enter 执行。Esc 可收起菜单。普通文字不会触发命令菜单。

| 命令 | 功能 |
| --- | --- |
| `connect` | 选择 DeepSeek，隐藏输入并保存 API Key |
| `models` / `model` | 实时获取并选择 DeepSeek 模型，保存选择 |
| `session` / `sessions` | 选择历史会话并恢复完整上下文 |
| `session new` / `new` | 开始新会话 |
| `session <ID或唯一前缀>` | 恢复指定会话 |
| `help` | 显示帮助 |
| `exit` / `quit` | 退出 |

也可以从终端直接打开对应流程：

```bash
npm start -- connect
npm start -- session
```

首次发送成功后自动保存会话，用首条消息作为标题。每次启动默认开启新会话，可通过 `session` 继续历史。空会话不保存。回复期间 Ctrl+C 中断请求，本轮不写入历史；输入期间 Ctrl+C 退出。

## 本地数据

- `~/.roco/config.json`：提供商和 API Key，明文存储，文件权限为 `600`。
- `~/.roco/sessions/`：历史问答，文件权限为 `600`。
- `ROCO_HOME`：可选，自定义数据目录。
- `DEEPSEEK_API_KEY`：可选，优先于本地保存的 Key。

对话时会向 DeepSeek 发送当前会话的全部消息；不同会话之间不共享上下文。连接命令只保存配置，随后自动获取模型列表验证 Key；获取失败时可重新运行 `models`。环境变量 Key 优先用于模型列表和对话请求。

当前调用官方 `https://api.deepseek.com/chat/completions`，默认使用 `deepseek-flash`，选择后使用所选模型，关闭思考模式。模型设置全局生效，切换或恢复会话时沿用当前选择，不清空已有上下文。输入 `/models` 可实时刷新列表；接口有返回时菜单会显示模型名称、上下文和最大输出信息。
参考：[DeepSeek API](https://api-docs.deepseek.com/)。

## 图片输入

支持 PNG、JPEG、GIF、WebP，每条消息最多 4 张，每张最多 10 MB（客户端限制）。在 `/models` 中选择标有“支持图片”的模型，然后直接输入图片路径或使用 `/image`：

```text
/image /Users/你的用户名/Desktop/demo.png 描述一下这张图
看看这张图片 "./images/screen shot.png"
/image ./front.png ./back.jpg 比较这两张图片
```

支持绝对路径、相对当前启动目录的路径、`~/` 路径；含空格路径请加引号，也支持终端拖入产生的 `\ ` 转义。只有图片时默认请求描述图片。远程图片链接目前作为普通文本发送。

本地图片会编码后发送给 DeepSeek，图片快照与消息一起保存在本地历史中，因此删除源文件后仍可继续会话。恢复历史只显示图片标记与路径，不输出编码。每轮含图片上下文的请求都会检查模型接口返回的 `input_modalities`；未声明支持图片时提示切换模型，不会默默丢弃图片。

## 通过 SSH 对话（本地测试）

项目自带独立 SSH 服务，不依赖系统 sshd，不需要管理员权限，也不需要创建系统用户。支持 macOS / Linux，要求系统可运行 `ssh-keygen`（默认自带 OpenSSH）；`node-pty` 使用本地原生模块，缺少预编译包的平台可能需要编译工具。

在项目目录开启服务，并保持此终端运行：

```bash
npm run ssh
```

在另一个终端执行（也可直接复制服务启动时输出的命令）：

```bash
ssh -tt -i ~/.roco/ssh/client_ed25519 -p 2222 roco@127.0.0.1
```

首次连接会询问是否信任主机，请将显示的 SHA256 指纹与服务启动日志核对后确认。成功连接后直接进入 Roco，可用 `/connect`、`/models`、`/session` 和 Tab 补全；输入 `exit` 或 Ctrl+C 退出聊天即断开 SSH。启动服务的终端按 Ctrl+C 停止整个服务。

首次启动生成专用主机密钥及测试客户端密钥，存于 `~/.roco/ssh/`，私钥权限为 `600`。只接受用户名 `roco` 和对应公钥，不支持免认证访问、密码登录、远程命令执行、SFTP 或转发。客户端私钥需要保存在发起连接的机器上，不要上传仓库或公开分享。

SSH 会话使用服务进程的 `ROCO_HOME`（默认 `~/.roco`），与本地 CLI 共用模型配置和历史。每次连接启动独立聊天进程，默认新建会话，可用 `/session` 恢复；目前属于同一用户的数据空间。连接中断会终止该次聊天进程，已经成功保存的问答仍然保留。

**图片路径指向运行服务的机器。** 本地回环测试时仍可用本机路径；未来换成远程服务器后，客户端电脑的图片不会因为输入本地路径而自动上传。

可选环境变量：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `ROCO_SSH_HOST` | `127.0.0.1` | 监听地址，仅本机访问 |
| `ROCO_SSH_PORT` | `2222` | SSH 服务端口 |
| `ROCO_SSH_PUBLIC_KEY` | 自动生成的客户端公钥 | 指定允许登录的公钥文件（单个 OpenSSH 公钥） |
| `ROCO_HOME` | `~/.roco` | 配置、历史和服务密钥目录 |

后续部署到服务器时可指定监听地址和端口，并配置对应防火墙入口；本轮默认仅开放本机回环地址。
